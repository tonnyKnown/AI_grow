## 项目速览

**OA 智能办公管理系统**：Spring Cloud 微服务 + Vue 3 前端 + JavaChain AI 能力。

| 维度 | 内容 |
| --- | --- |
| 核心模块 | 系统管理（RBAC）、业务管理（商品/订单/营销/物流）、AI 智能能力（对话/RAG/Agent/MCP） |
| 技术栈 | JDK 21、Spring Boot 3、Spring Cloud、Nacos、MySQL、Redis、Vue 3、Vite、LangChain4j |
| 服务数量 | 5 个后端服务 + 1 个前端 |
| 架构模式 | 微服务 + API 网关统一入口 |

详细的架构说明见 [TRD 技术设计文档](02-技术/TRD-技术设计文档.md)。

## 文档维护

> ⚠️ **不要直接改文档**。任何变更先立 Issue，评审通过后**先归档旧版本、再改正文**，并更新文末「变更记录」表。
> 完整规则见 [需求开发流程](06-规范/需求开发流程.md)、[变更管理规范](06-规范/变更管理规范.md) 与 [迭代与版本规划规范](06-规范/迭代与版本规划规范.md)；具体写法见 [文档编写规范](06-规范/文档编写规范.md)。

| 代码变更 | 需同步更新 |
| --- | --- |
| 新增/修改接口 | [API 接口文档](03-接口/API-接口文档.md) |
| 数据库表结构变更 | [数据库设计文档](04-数据库/数据库设计文档.md) + `sql/` 脚本 |
| 新增功能模块 | [PRD](01-产品/PRD-产品需求文档.md) |
| 架构调整 | [TRD](02-技术/TRD-技术设计文档.md) |
| 部署方式变更 | [部署运维手册](05-运维/部署运维手册.md) |
| 新增规范约定 | [开发规范与贡献指南](06-规范/开发规范与贡献指南.md) |
| 流程调整 | [需求开发流程](06-规范/需求开发流程.md) / [变更管理规范](06-规范/变更管理规范.md) |
| 迭代机制调整 | [迭代与版本规划规范](06-规范/迭代与版本规划规范.md) |
| 文档结构或格式约定调整 | [文档编写规范](06-规范/文档编写规范.md) |
| 发布版本 | [CHANGELOG](CHANGELOG.md) |
| 仓库结构变化 | [CODEBUDDY.md](../CODEBUDDY.md) |

**每次改动文档的三件套**：

1. **改正文** — 按当前有效需求调整内容
2. **升版本号** — 文档头部「文档版本」递增（规则见[变更管理规范 · 版本号规则](06-规范/变更管理规范.md#2-版本号规则)）
3. **记变更** — 文末「变更记录」表新增一行（版本、日期、变更内容、关联 Issue、修改人）

**新增文档时**：放入对应的编号目录 `docs/<NN-分类>/`，并回到本页登记索引。
